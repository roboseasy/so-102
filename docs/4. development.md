# SO-102 LeRobot 플러그인 개발

## 설치와 자동 발견

```bash
conda activate lerobot060
python -m pip install -e . build
python -m pip check
```

배포 이름과 진입 모듈은 `lerobot_robot_so102`다. LeRobot v0.6.0의 `register_third_party_plugins()`는 이 접두사로 시작하는 설치 배포를 찾아 모듈을 가져온다. 이 모듈은 팔로워·리더 설정을 각각 공식 ChoiceRegistry에 등록한다. 팩터리는 등록한 설정 클래스에서 SO-102 장치 클래스를 찾는다.

`lerobot-teleoperate`, `lerobot-calibrate`, `lerobot-record`의 시작 지점에는 플러그인 탐색이 있다. 현재 통합 시험은 기본 teleoperate·calibrate 경로를 대상으로 하며 녹화 장비·데이터셋·정책 학습은 별도 검증한다. LeRobot 파일이나 콘솔 진입점은 교체하지 않는다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `src/lerobot_robot_so102/__init__.py` | 자동 발견 및 두 타입 등록 |
| `lerobot_devices.py` | 공식 SOFollower·SOLeader와 설정을 상속하고 7축 버스 구성 |
| `config.py`, `hardware.py`, `runtime.py` | 이전 보조 도구의 설정·진단·가상 실행 |
| `commands.py`, `cli.py` | `so102` 보조 명령 |
| `tests/test_native_plugin.py` | 공식 CLI 자동 발견·파싱·보정·실행 통합 시험 |

## 검증

```bash
conda activate lerobot060
python -m unittest discover -s tests -v
lerobot-teleoperate --robot.type=so102_follower --teleop.type=so102_leader --help
lerobot-calibrate --robot.type=so102_follower --help
python -m build
```

공식 CLI 통합 시험에서는 실제 LeRobot main·파서·processor·제어 루프를 사용하고 시리얼 버스만 대체한다. 새 프로세스의 배포 메타데이터 자동 발견도 검사한다. 장비에 모터 명령을 보내지 않는다.

CI는 Conda `lerobot060`과 CPU PyTorch에서 위 경로를 검사하도록 구성한다. 원격 워크플로 실행 결과는 아직 없다.

## 카메라와 보정

팔로워의 카메라 설정·관측 특성은 기본 SOFollower 구현을 상속한다. 기본 카메라 구성은 `{}`다. 모터 구성은 shoulder_pan(1), shoulder_lift(2), elbow_flex(3), wrist_flex(4), wrist_yaw(5), wrist_roll(6), gripper(7)이다.

보정값은 공식 Robot·Teleoperator의 기본 경로와 표준 JSON을 사용한다. 역할별 `name`과 `id`로 경로가 구분된다. 보정·저장 구현도 공식 클래스를 그대로 상속한다. 추가 축 `wrist_yaw`를 포함한 6개 관절은 범위를 측정하고 `wrist_roll`은 공식 방식인 0~4095를 사용한다. 이전 보조 CLI의 envelope 형식 보정 파일과 혼용하지 않는다.

연결·모터 설정·관측·리더 입력·팔로워 출력·종료는 공식 SO-100/101과 동일한 메서드를 사용한다. SO-102 전용 생명주기나 초기 자세 검사, 보정 범위 검사를 덧붙이지 않는다. 설정 클래스도 필드와 기본값을 그대로 상속하며, `max_relative_target`은 공식 기본값인 `None`이다. 이 값을 지정했을 때만 공식 상대 목표 제한을 적용한다.

## 배포

```bash
conda activate lerobot060
python -m build
python -m pip install dist/lerobot_robot_so102-0.1.0-py3-none-any.whl
```

소스 배포본에는 환경 파일·포트 규칙 템플릿·문서·테스트·렌더링 도구를 포함한다. wheel은 플러그인과 상대 경로 URDF 1개·STL 12개를 포함한다.

이전 `roboseasy-so102` 배포를 설치한 개발 환경은 해당 배포를 제거하고 위 플러그인을 설치한다. 기본 실행 안내는 이 저장소의 README를 따른다. 기존 보정·실장비 설정은 자동 변경하지 않는다.

```bash
python -m pip uninstall roboseasy-so102
python -m pip install -e .
```

출시 전에는 실제 모터·보정·추종·종료 시험, 출고 설정값, 새 PC 설치 재현, 자체 코드와 CAD/STL 배포 라이선스 및 제품 사진을 확인한다. 외부 업로드·릴리스는 수행하지 않았다.
