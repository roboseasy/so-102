# SO-102 USB 포트 고정

[사용자 위키독스의 USB 포트 고정 안내](https://wikidocs.net/385992)를 SO-102 이름에 맞춰 적용한다. 아래 작업은 Linux의 udev 설정이며 Conda 환경과 별개다.

## 1. 역할과 보드 식별

현재 확인된 연결은 리더 `/dev/ttyACM0`, 팔로워 `/dev/ttyACM1`이다. USB 재연결로 번호가 바뀔 수 있으므로, 연결된 보드의 역할을 확인한 다음 `ID_SERIAL_SHORT` 값을 읽는다.

```bash
udevadm info --query=property --name=/dev/ttyACM0
udevadm info --query=property --name=/dev/ttyACM1
```

## 2. 규칙 작성과 적용

```bash
cp config/99-so102.rules.example config/99-so102.rules
nano config/99-so102.rules
```

`REPLACE_LEADER_SERIAL`과 `REPLACE_FOLLOWER_SERIAL`을 각각 확인한 실제 USB serial로 교체한다. 두 값은 달라야 한다. 이 파일은 장비별 개인 설정이므로 Git에서 제외한다.

```bash
sudo install -m 0644 config/99-so102.rules /etc/udev/rules.d/99-so102.rules
sudo udevadm control --reload-rules
```

USB를 다시 연결한 뒤 확인한다. 로봇을 제어하는 프로그램을 종료하고 수행한다.

```bash
ls -l /dev/so102_leader /dev/so102_follower
readlink -f /dev/so102_leader
readlink -f /dev/so102_follower
```

두 별칭이 각각 올바른 보드를 가리키는지 확인한다. 위 규칙 파일은 자동 설치되지 않으며, 플러그인 설치만으로 `/dev/so102_*`가 생성되지는 않는다.

## 3. 접근 권한

```bash
id -nG
sudo usermod -aG dialout "$USER"
```

이미 `dialout`에 등록되어 있다면 추가 명령은 생략한다. 등록 직후에는 로그아웃·재로그인하고 IDE/Codex도 재시작한다. 현재 세션의 `id -nG`에 `dialout`이 있어야 한다.

## 별칭 없이 사용하기

포트를 고정하지 않았다면 명령의 `--teleop.port`와 `--robot.port`에 실제 확인한 `/dev/ttyACM0`, `/dev/ttyACM1` 또는 `/dev/serial/by-id/...` 경로를 지정해도 된다. `--*.id`는 포트와 별개인 보정 파일 식별자이므로 장치마다 일관되게 유지한다.
